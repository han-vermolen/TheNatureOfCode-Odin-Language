# Use of AI
This project uses AI to generate documentation and keep track of the roadmap.
Occasionally, AI might be used to create commit messages.

⚠️ **Important:** Humans wrote all code.

# Statement on the use of AI.
If you wish to contribute to this project, please do not use AI to generate code. However, feel free to use AI to:
* explain concepts
* find bugs, but verify by hand. There's no bug until you have a hand-written test. 😊
* write documentation
* if anything is written by AI, add a note to it that states so. (Examples are in this repo.)
